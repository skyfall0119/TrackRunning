# TrackRunning (트랙런닝)

TrackRunning is a simple and effective interval training app for runners.

[Download on Google Play Store](https://play.google.com/store/apps/details?id=com.jaykim.trackrunning&hl=ko)

---

## 변경 내역 (Changelog)

### v1.13.1 (versionCode 8) — 2026-09-27

**버그 수정**
- 프리셋 편집 화면에서 백그라운드 스레드가 UI를 직접 갱신하던 문제 수정 (`CalledFromWrongThreadException`으로 인한 강제 종료 가능성 제거)
- DB 로딩이 끝나기 전에 프리셋 추가/완료 버튼을 눌러 발생할 수 있던 크래시 방지 (로딩 중 버튼 비활성화)
- 휴식 중 STOP을 눌러도 휴식 카운트다운이 계속 실행되던 문제 수정
- 운동을 중간에 종료할 때 기록되지 않은 랩이 "00:00.00"으로 저장되던 문제 수정
- 활동/프리셋 상세 화면이 목록 위치(position)가 아닌 DB id로 항목을 조회하도록 수정 (다른 기록이 열리거나 크래시 나던 문제)
- 최고/평균 기록 통계 계산에서 휴식 항목이 포함되던 문제 수정
- 운동 기록 저장이 끝나기 전에 화면을 나가면 기록이 유실될 수 있던 문제 수정, 저장 실패 시 오류 메시지 표시
- 화면 회전 시 진행 중이던 운동 상태(랩, 경과 시간, 휴식 여부)가 초기화되던 문제 수정
- Fragment의 비동기 작업이 화면 전환 이후 남아있던 뷰를 건드려 발생할 수 있던 크래시 방지
- DB 스키마 변경 시 사용자 데이터가 통째로 삭제될 수 있던 위험 제거 (destructive migration 제거)
- 휴식 항목을 선택해도 통계가 바뀌던 문제 수정 (휴식 항목 선택 비활성화)
- 프리셋 제목이 길 경우 화면 밖으로 잘리던 문제 수정

**새 기능**
- 네비게이션 드로워에 "타이머" 메뉴 추가 — 시작/일시정지, 랩 기록, 초기화가 가능한 독립 스톱워치
- 랩 기록 시 전체 시간과 함께 랩 타임(스플릿)을 나란히 표시
- 전체 시간과 별도로, 랩을 찍을 때마다 0부터 다시 시작하는 "현재 랩" 시간 표시 추가
- 화면 회전 시에도 스톱워치 진행 상태(경과 시간, 랩 목록)가 유지되도록 처리
