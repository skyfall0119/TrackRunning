# agents.md

## General Rules

1. Follow existing project conventions before introducing new patterns.
2. Do not modify unrelated files.
3. do not create md files unless asked to do.
4. When unsure about requirements, ask for clarification instead of guessing.
5. Avoid adding new dependencies unless clearly necessary.
6. test will be done by the developer. 

---

## Code Style

* Use clear and descriptive variable names.
* Functions should do one thing and be short when possible.
* Avoid deeply nested logic.
* Prefer composition over inheritance.
* Remove unused code and imports.

---

## Development Workflow

When implementing a task:

1. Understand the requirement
2. Identify affected modules
3. Implement minimal change
4. Ensure code consistency
5. Add or update documentation if needed


---

## Refactoring Rules

Refactoring is allowed when:

* It reduces complexity
* It improves readability
* It removes duplication

Avoid large refactors unrelated to the task.
